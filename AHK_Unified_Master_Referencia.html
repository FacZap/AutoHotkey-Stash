AHK_Unified_Master.ahk

Referencia completa de hotkeys, hotstrings y funcionalidades — generada 100% a partir del contenido real del archivo unificado.

Cómo leer esto: cada sección corresponde a un bloque del script (identificado con comentarios ; ==== dentro del .ahk, con el nombre del script original del que proviene). El mantener presionado indica una acción que se repite mientras se mantiene el botón del mouse. El ventana indica que abre una interfaz gráfica.
