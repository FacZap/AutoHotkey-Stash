AHK_Unified_Master.ahk

Referencia completa de hotkeys, hotstrings y funcionalidades — generada 100% a partir del contenido real del archivo unificado.

Cómo leer esto: cada sección corresponde a un bloque del script (identificado con comentarios ; ==== dentro del .ahk, con el nombre del script original del que proviene). El mantener presionado indica una acción que se repite mientras se mantiene el botón del mouse. El ventana indica que abre una interfaz gráfica. El aux marca el apéndice del final: scripts que corren como procesos aparte del master, cuyos hotkeys existen solo mientras ese script esté corriendo.

Al iniciar el script

AcciónQué hace
Lanzamiento automáticoAl arrancar, además de armar todos los hotkeys de arriba y mostrar el AHK Manager, ejecuta RBTray.exe y abre el acceso directo de Wise Reminder.lnk (con una pequeña pausa de 200 ms antes).

Scripts auxiliares aux

Nada de lo que sigue está en el script maestro. Son procesos aparte — marcados con aux — que se lanzan desde el botón Aux Scripts… del Manager, o al iniciar el master según aux-scripts.ini. Sus hotkeys existen solo mientras el script esté corriendo: si no lo lanzaste, la tecla no hace nada y conserva su comportamiento nativo de Windows. Para ver cuáles están activos, esa misma ventana los marca como [corriendo] o [detenido], y aparecen en la lista del Manager. Tampoco se pueden apagar desde Hotkeys…: ese menú solo alcanza a los hotkeys del propio master.
